# Unova Together beta 0.3.12 — Clearer menus and co-op tools

- **Back buttons fixed:** submenus now return to the correct parent.
- **Simpler menus:** open **Players → Tools**. Pokémon tools, co-op settings, game options and the trainer card now have separate entries.
- **Pokémon tools:** IVs/EVs, the encounter finder, move relearning and follower controls are together.
- **Co-op settings:** choose Solo or Co-op trainer battles before talking to an NPC. **Practice battles** are rematches with no story rewards; **PvP battle** challenges another player.
- **Battle previews:** select a teammate in Players, then use **Tools → Co-op → Watch teammate**. The battler must enable **Let friends watch**. Both screens appear in a separate window at two snapshots per second, with no remote controls or audio.
- **Followers:** show or hide your own follower or teammates' followers. Nearby followers can greet each other.
- **Teammate status:** clearer labels for menus, waiting for a partner, battle preparation and active battles.

Update **every player**, then restart the player-sharing relay using this version. Existing launcher users can use **Updates**; restart the emulator after updating. No new ROM or save is required. Download **Unova-Together.exe**, or extract the Windows ZIP and run **Start Unova Together.cmd**.

Previews are off by default. On slow connections, preview frames are dropped so they do not fill the status/interaction queue. Try the software renderer if a preview is blank or stale. Internet preview testing is still needed. Co-op battle experience remains disabled; other existing beta limitations are listed in [known issues](https://github.com/WhatWasMissing/Unova-Together/blob/main/docs/KNOWN_ISSUES.md).

The native menu fixture, relay tests and story-return checks passed. A muted two-instance Cheren practice battle completed on both games at about 59–60 FPS. This does not verify every story award or internet connection. See the [co-op tools guide](https://github.com/WhatWasMissing/Unova-Together/blob/main/docs/COOP_TOOLS.md).

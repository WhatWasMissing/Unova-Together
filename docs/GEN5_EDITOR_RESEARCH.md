# Keep your game and save files safe

Unova Together does not include Pokémon game files, saves, or firmware. Choose your own supported game file in the launcher and keep a backup of saves you care about.

The launcher’s optional Generation 5 tools are read-only helpers for supported games. They do not replace the game’s normal save menu. See [Games, saves, and Pokémon tools](LAUNCHER_GEN5_TOOLS.md) and [Manage game copies and storage](LAUNCHER_STORAGE.md).

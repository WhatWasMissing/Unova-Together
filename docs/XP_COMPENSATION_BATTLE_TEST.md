# About solo battle experience

Supported solo battles award **1.25×** experience. Co-op battles use normal game rewards by default; for comparison tests, enable **Suppress EXP in co-op battles** in launcher Settings on both computers. The solo bonus does not change existing experience or save files outside normal battle rewards.

See [Solo battle experience](XP_COMPENSATION.md) for details and [Features](FEATURES.md) for other game additions.

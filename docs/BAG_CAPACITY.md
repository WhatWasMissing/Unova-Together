# Bag capacity and Mega Stone shops

The bag keeps the standard capacity from Blaze Black 2 Redux. This update does not change bag storage or alter save files. Mega Stones use existing item entries, so players can collect them without a bag-format change.

Poké Marts alternate between two Mega Stone selections, making all 49 stones available around Unova for ₽50,000 each. Both Battle Point counters also offer all 49 for 50 BP. The shops keep their original items alongside the stones.

Increasing the bag limit safely would require a change to the game's save format. That needs to preserve existing saves and pocket contents, so it is not part of this release.

# Soaring flight preview

Soaring is an **unfinished, optional preview** that lets you fly between 69 outdoor areas in Blaze Black 2 Redux. Named towns and routes guide the regional map, and added terrain helps the scenery flow between separated locations. Some positions and transitions are approximate.

## Start a flight

1. In launcher settings, turn on **Experimental features → Soaring flight**.
2. Start your game and open **Unova → Pokémon → Take flight**.
3. Use the on-screen prompts to move through the air.
4. Land only on clear ground. If no safe landing is available, choose the option to return to your take-off point.

Some connector terrain is scenery only and cannot be used as a landing spot. Land only where the game offers clear ground. Marine Tube has no safe landing spot; save normally before using the preview and return to your take-off point there.

Soaring is separate from the game’s usual Fly move. It does not change your save or the normal story requirements for Fly. For regular travel, use the game’s party menu.

For other limits, see [Known limits](KNOWN_ISSUES.md).

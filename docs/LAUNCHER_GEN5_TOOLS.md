# Games, saves, and Pokémon tools

The launcher includes optional read-only tools for supported Generation 5 games. They can check whether a game profile is recognized, compare copied save data, and estimate experience progression for Blaze Black 2 Redux Challenge mode.

The tools do not distribute a game ROM or save and do not replace the game’s own save menu. Use **Games & saves** to manage your game slots, make backups, or restore a saved copy. Keep a recent backup before changing game files.

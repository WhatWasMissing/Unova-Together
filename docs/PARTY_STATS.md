# Party IVs and EVs

Open **Players → Tools → Pokémon → IVs and EVs**, then choose a Pokémon. This works offline.
Use the controller's directional buttons and A, or tap a party entry. B returns
to the party; B again returns to Game. X closes the custom menu.

The table shows HP, Attack, Defense, Sp. Atk, Sp. Def and Speed in that order.
IVs range from 0–31. Black 2 stores up to 255 EVs per stat; the total limit is 510.
This screen reads the actual stored values, including any unusual values from
an edited save. It does not edit stats or award experience.

Return to the field before opening it. If the party cannot be validated, the
viewer shows an unavailable message instead of guessed or previous values.

The sprites and viewer are supplied by the emulator build. No ROM patch or new
save is needed. The Pokémon in the first party slot follows you if it is neither fainted nor an egg,
when Following Pokémon is enabled in Multiplayer → Players.

All 649 base species have directional follower artwork. Full shiny, gender and
alternate-form coverage is not included. Gen 5 artwork is credited to the
hg-engine artists; see the included follower credits.

# Pokémon Together launcher guide

Use the launcher to choose a supported Pokémon Black 2 or Blaze Black 2 Redux game, start Unova Together, connect with friends, and keep your game up to date.

## Choose a game and save

Open **Unova Together** in **Mod library**, choose your own compatible game file, then select **Play**. The launcher can keep separate game slots and save backups. Your ROMs and saves stay on your computer.

Use **Games & saves** to manage profiles, backups, or save slots. **Tools** includes file checks and cleanup for older game copies. Save in the game before closing the emulator or restoring an older save.

## Connect with friends

Choose **Co-op** in the launcher to host or join a local game. For friends on different networks, follow the [Tailscale guide](TAILSCALE_COOP.md). The optional UDP connection requires a server supplied by your group.

Everyone should use the same Unova Together release and matching game revision. Turn off fast-forward before connecting. For steps, see the [Player guide](PLAYER_GUIDE.md).

## Launcher pages

- **Mod library:** choose Unova Together or another listed game.
- **Play:** choose a game file and start the emulator.
- **Co-op:** host or join a session and manage connection details.
- **Features:** browse available additions and guides.
- **Games & saves:** manage slots and backups.
- **Updates:** check for and install the latest release.
- **Settings:** adjust controls, display, audio, music, and reduced motion.
- **Tools:** check installed files, repair a game installation, or clean up older copies.

## Updates and repairs

The launcher downloads official releases and checks their integrity before installing. Updates are placed beside the current version, so you can finish a session before switching. Save files and settings stay in place.

Close the emulator before opening another game session. If a download is interrupted, the current installation remains available. Use **Tools → Repair game files** if files are missing or damaged.

## Reports and privacy

**Tools → Report a problem** prepares a troubleshooting file for you to review. Nothing is sent automatically. Check the contents before sharing it. The report excludes ROMs, saves, RAM dumps, and credentials.

For optional-feature and connection information, see [Known limits](KNOWN_ISSUES.md). The launcher’s Generation 5 helpers are described in [Games, saves, and Pokémon tools](LAUNCHER_GEN5_TOOLS.md).

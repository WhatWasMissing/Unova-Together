# About the Soaring preview

Soaring is an optional flight preview across 69 outdoor areas in Blaze Black 2 Redux. The regional view now follows named places and their connecting routes, with terrain that bridges gaps between separated areas. Some positions and transitions are approximate, and safe landing places remain limited.

Land only where the game identifies clear ground. Some connecting scenery is for the view and cannot be used as a landing spot. Marine Tube has no safe landing spot; return to your take-off point there.

See the [Soaring flight guide](SOARING_FLIGHT.md) for how to turn it on and use it. The normal Fly move remains available through the game’s party menu.

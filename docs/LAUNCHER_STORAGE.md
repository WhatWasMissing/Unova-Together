# Manage game copies and storage

The launcher can remove older Unova Together game copies to free disk space. Open **Tools → Clean old installations** or let cleanup run when the launcher starts.

The launcher keeps the active game, the previous version for recovery, and files needed by a running game. It also keeps your saves, save backups, settings, ROMs, firmware, and files you added or changed. A few small folders may remain if they contain custom files.

Updates and repairs are installed in a separate folder and checked before the launcher switches to them. If a download is interrupted or incomplete, your current game stays active.

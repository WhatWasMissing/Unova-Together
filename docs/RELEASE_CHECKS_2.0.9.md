# Unova Together 2.0.9 release checks

The supported English Blaze Black 2 Redux Complete v1.4.1 game was used to check this update. Every Poké Mart and both Battle Point counters offer all 49 Mega Stones, with their names, artwork, prices, and original shop items intact. The game and launcher downloads are built for Windows and include the 2.0.9 patch notes.

# Mega Evolution test

Unova Together 1.0.22 includes the custom Mega Serperior form for the supported English Pokémon Black 2 Redux Complete v1.4.1 ROM (`IREO`). No other Mega forms are enabled in this build.

Give Serperior Serperiorite (reserved item slot 113). If you need the stone, open the emulator's Multiplayer panel while standing idle in the overworld with C-Gear wireless off, select **Debug**, choose **Serperiorite**, then select **Grant Mega Stone (debug)**. Save normally if you want to keep the item.

In battle, open **Fight** and press **L + R together** at the move-selection screen. Mega Serperior keeps Grass/Dragon typing and changes from Contrary to Sap Sipper. The change lasts through battle and does not alter the saved party record. The custom art uses static front/back sprites packed as native DS 4bpp tiles and palettes.

This build also falls back to Serperior's supported base-form party icon and palette when the battle Pokémon menu asks for resources the Redux ROM does not contain for Mega form 1. The Mega battle form and sprite remain active. Please test opening the Pokémon menu after Mega Evolution and complete the battle; that menu path has not yet been confirmed in a live game session. The public Mega regression suite and exact ROM hook-signature test pass. A live two-player Mega battle still needs a test.

No ROM, save, firmware or RAM capture is included. Use an independent backup and save normally before trying a new feature. The user confirmed the supplied Mega Serperior sprite may be used in this free, non-commercial mod. The source file has no reliable creator metadata, so it is credited as user-provided fan artwork rather than claimed as original project art.

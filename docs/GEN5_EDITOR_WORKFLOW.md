# Working with a supported game

Choose your own compatible English Blaze Black 2 Redux game file in the launcher. No full Unova Together game patch is currently bundled; if one is released for your Redux version, use a copy patched with the file listed for that exact version. Unova Together does not include or download a game file, save, or firmware.

Use **Games & saves** for backups and save slots. Optional Generation 5 helpers can inspect compatible copies without replacing the game’s own save menu. For setup, see the [Player guide](PLAYER_GUIDE.md).

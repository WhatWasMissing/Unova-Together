# Follower variant provenance

Unova Together by mvq1303 / WhatWasMissing. Conversion/maintenance by OpenAI Codex at the author's request. Artwork retains its original authorship.

The development asset set contains **743** BTX variants from [hg-engine](https://github.com/BluRosie/hg-engine), pinned to commit **5f1c91fb93ee6d78cf54105ecf1ce1933e043dad**. The builder verifies downloaded Git blobs and SHA-256 hashes; `maintenance-tools/assets/followers/variants/manifest.json` identifies each generated asset, source directory and output hash. `build_follower_variants.py` records source paths and author-provided normal/shiny palettes.

Preserve [the bundled credits](../maintenance-tools/assets/followers/CREDITS.md) and [asset terms](../maintenance-tools/assets/followers/ASSET_TERMS.md). These retain Nintendo/Game Freak and individual contributor credits. The GPL code license does not relabel Nintendo-derived artwork as original project work.

All 649 base species are covered. Authored variations include female appearances, Unown, Castform, Deoxys, Burmy/Wormadam, Cherrim, Shellos/Gastrodon, Rotom, Giratina, Shaymin, Gen 5 Arceus types, Basculin, Darmanitan, Deerling/Sawsbuck seasons, Therian formes, Kyurem, Keldeo, Meloetta and Genesect drives. Coverage follows available source assets; it does not promise every gender/form appearance. Unsupported forms use base art rather than a different species.

BTX files preserve indexed pixels and 32/64-pixel dimensions. The runtime adds transparent walking headroom and common frame canvases, uses the real record's form/gender/shininess and retains normal Gen 1–4 sprites from the player's loaded cartridge where appropriate. It does not download art during gameplay.

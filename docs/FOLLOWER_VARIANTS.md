# Follower artwork

All 649 base species have directional follower artwork. Shiny colors and selected gender or alternate-form artwork are available where matching images were supplied. When a matching alternate-form image is not available, the base artwork is used.

The follower art keeps its original creator credits. See [Follower art credits](FOLLOWER_ART_CREDITS.md) and [source artwork terms](FOLLOWER_ART_TERMS.md). For use in the game, see [Following Pokémon](FOLLOWING_POKEMON.md).

# Player help

This folder contains extra files used by the project and is not needed for normal play. Download Unova Together from the [official release page](https://github.com/WhatWasMissing/Unova-Together/releases/latest), then use the launcher to choose your game, manage saves, connect with friends, and update.

Start with the [Player guide](../docs/PLAYER_GUIDE.md), [launcher guide](../docs/LAUNCHER.md), and [Known limits](../docs/KNOWN_ISSUES.md). Your game ROM and save remain on your computer.

For game-data research, see the attributed [Generation 5 reference index](../docs/GEN5_RESEARCH_REFERENCES.md).

Money and repel codes are from libretro/libretro-database, Nintendo DS, Pokemon - Black Version 2 (USA, Europe).cht.

The Rare Candy entry is a single-slot adaptation of that database's All Medicines code by mvq1303 / WhatWasMissing. The adapted code catalog is CC BY-SA 4.0; see CHEATS-LICENSE.txt. No endorsement is implied.

Compatibility is restricted to reviewed ARM9 fingerprints, not ROM filenames. Redux built-in features are documented at https://github.com/zhenga8533-archive/bbvw2-redux-wiki/blob/main/data/documentation/Useful%20Action%20Replay%20Codes.txt

Codes require in-game activation and apply to your independent save. Disabling a code does not undo saved money/items. XP, story flags and battle behavior are not modified by this catalog.

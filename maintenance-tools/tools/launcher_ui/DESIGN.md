# Launcher help

To choose a game, connect with friends, manage saves, change settings, or install an update, follow the [launcher guide](../../../docs/LAUNCHER.md). For getting started, read the [Player guide](../../../docs/PLAYER_GUIDE.md).

The launcher keeps your game data on your computer and checks downloaded updates before installing them. See [Known limits](../../../docs/KNOWN_ISSUES.md) for connection and optional-feature details.

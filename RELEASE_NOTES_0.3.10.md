# Unova Together beta 0.3.10 — Followers and party stats

- All 649 Pokémon have directional follower sprites. The remaining Gen 5 party-icon substitutes have been replaced.
- Repeated standing poses now have a small movement bob.
- View IVs and EVs in **Players → Game → Party stats**. This works offline and does not change the Pokémon.
- The launcher Features page includes a screenshot of the stats viewer.

Download **Unova-Together.exe**, or extract the Windows ZIP and run **Start Unova Together.cmd**.
Existing users can install this release from the launcher's Updates page.
No new ROM or save is required. Restart the launcher and emulator to use the new build.

Gen 1–4 follower art comes from your own ROM. The additional Gen 5 art comes from
the hg-engine artists, with full credits included. Shiny and complete alternate-form
appearances remain outside this update.

All 649 species passed directional and animation checks against Black 2, Redux
and Unova Together. The native menu checks passed on a copied save, including
Options, Trainer Card and the new stats screen. This is not a playtest of every
species on every map; existing networking beta limitations still apply.

Keep C-Gear wireless and fast-forward off for co-op. Co-op experience remains disabled. See [known issues](https://github.com/WhatWasMissing/Unova-Together/blob/main/docs/KNOWN_ISSUES.md) for the remaining beta limitations.

# Unova Together 1.0.24 — 12 Mega forms to test

This build adds an experimental Mega form for each of these Pokémon: Serperior, Arcanine, Aggron, Altaria, Banette, Gallade, Heracross, Latios, Manectric, Sableye, Salamence, and Scizor.

Use **Multiplayer → Debug** to grant a matching Mega Stone, then use **L + R** while choosing a move in battle. Mega forms last for that battle only. Save normally before testing; all forms and linked two-player battles still need live playtesting.

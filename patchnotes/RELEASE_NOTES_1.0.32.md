# Unova Together 1.0.32 — Soaring across Unova

- Experimental Soaring now reaches all 69 outdoor areas supported by this build, including Black City.
- Clear landing spots return through the game's Fly-style transition.
- Places without safe ground keep the option to return to take-off.

To try it, enable **Settings → Experimental features → Soaring flight**, then choose **Unova → Pokémon → Take flight**. Fly between a few routes and towns, land on clear ground, and check that you return to the right map and spot. Soaring remains experimental, so please save before testing.

# Unova Together 1.0.22 — Mega Serperior menu fix

- Fixed a crash that could happen when opening the Pokémon menu after Mega Evolving Serperior.
- Mega Serperior stays in its battle form; the menu uses its normal icon where the game has no Mega icon.
- The launcher and game now share version 1.0.22. Open your existing launcher and install the update to test its download feature.
- To check the battle fix, use Black 2 Redux Complete v1.4.1, Mega Evolve Serperior, open the Pokémon menu, and finish the battle.
- Mega Evolution remains experimental. Save normally first; a live two-player Mega battle still needs testing.

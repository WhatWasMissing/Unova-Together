# Unova Together 2.0.35 — Custom dialogue art tools

- Adds an exact-build developer patcher to the Windows and source downloads. It can add speaker portraits, nameplates, and dialogue frames for configured actor conversations in English Blaze Black 2 Redux Complete v1.4.1 (IREO).
- The patcher makes a separate ROM and refuses unsupported input or an existing output path. It does not change the source ROM, saves, event scripts, or dialogue text.
- Includes original Emma sample artwork and an exact nurse profile so you can try the renderer in Lentimas Town. The normal launcher and emulator gameplay binary are unchanged.

To try the boxes, use a copied save that can reach the Lentimas Town Pokémon Center, patch your own supported ROM, and run the silent isolated test in [Dialogue art testing](../docs/DIALOGUE_ART_TESTING.md). No ROM, save, or firmware is included. DSi mode, real hardware, two-client co-op, and other game revisions are not verified.

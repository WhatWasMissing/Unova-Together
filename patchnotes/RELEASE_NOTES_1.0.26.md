# Unova Together 1.0.26 — Mega Roster Expansion

- Adds 46 Mega Stone and form entries, bringing the roster to 49 Mega forms.
- Replaces unused Mail, Apricorn, and Data Card slots with named stones and matching icons. Pokémon Center Marts sell every stone for ₽50,000.
- To Mega Evolve, give the matching stone to a Pokémon and press **L + R together** while choosing a move. The form ends with the battle.
- Supplied GIF art is imported as static sprites for now. Native Gen 5 frame animation is still being investigated.
- Save normally before testing. Automated checks pass, but the expanded roster and linked co-op battles still need live testing.

# Unova Together 2.0.19 — Mega Stone shops, Teleport, and co-op testing

- Fixed a crash that could happen when opening a Poké Mart’s buy list. Mega Stones are split between alternating Marts, so all 49 remain available across Unova without overcrowding any one shop. Each stone costs ₽50,000.
- Restored the relay location updates needed by the in-game Teleport option.
- Added **Suppress EXP in co-op battles (testing)** to launcher Settings. It is off by default and applies the next time you launch; use the same choice on both computers when comparing co-op behavior.

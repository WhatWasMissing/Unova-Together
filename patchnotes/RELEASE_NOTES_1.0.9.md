# Unova Together 1.0.9 — A one-time launcher repair

- If an older shortcut keeps opening an outdated launcher, run Repair-Launcher.exe once and select the shortcut's original Pokémon Together.exe.
- Close the launcher if Windows asks; the repair never closes the game for you.
- Your ROMs, profiles, saves, and backups stay in place. See the launcher migration guide before running the repair.

# Unova Together 1.0.28 — Mega Pokémon animations

Mega Pokémon with supplied animated artwork can now play through the full set of GIF frames during battle. Mega Salamence is the main test for this update, with 67 frames.

Give Salamence Salamencite, then press **L + R together** while choosing a move. After it Mega Evolves, check whether its sprite cycles through the animation. Let us know if it stays still or looks misaligned.

This is a test build. Save normally before playing, and update every player before connecting together.

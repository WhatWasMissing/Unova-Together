# Unova Together 2.0.23

- Updated walking Pokémon with HGSS artwork for all 493 Generation 1–4 species, plus matching gender and alternate-form sprites.
- Shiny Pokémon keep their separate shiny artwork. Pokémon and forms missing from the HGSS sheets keep their existing sprites, including Generation 5.
- Pokémon Center Marts now carry three Mega Stones per inventory, with all 49 stones spread across Unova. Each costs ₽50,000. Battle Point counters still offer the full selection for 50 BP.

Use the same release and Blaze Black 2 Redux Complete v1.4.1 game version as your friends. Existing saves remain compatible.

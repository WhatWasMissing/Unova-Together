# Unova Together 1.0.34 — Mega Evolution and steadier follower poses

- Mega Evolution now has a featured place in the launcher, with quick examples and a guide to all 49 forms and their stones.
- Follower poses now line up by their visible artwork, preventing transparent image borders from making the Pokémon jump inside its frame.

The follower fix passes an automated test using matching artwork with different transparent padding. Please check it in-game and let us know if the bobbing now looks right. The optional Soaring preview is still unfinished.

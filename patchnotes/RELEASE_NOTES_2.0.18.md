# Unova Together 2.0.18 — Pokémon Center crash fix and launcher reliability

- Fixed a crash when entering a Pokémon Center.
- Cynthia is available through Practice rematches without the unsupported-trainer error.
- Updates and launcher repair handle damaged or incomplete setup information more safely. A failed update can be retried without replacing the current game.
- Save backups and restores use matching size and file-count limits. Damaged backups show a clear error and leave the current save intact.
- Old-version cleanup skips damaged installation records instead of stopping the whole cleanup.
- Games & saves, backup folders, and problem-report folders show clearer errors when files cannot be accessed or opened.
- The emulator-settings editor reports damaged settings sections instead of crashing.
- Prepared player-model games are checked before reuse, and cached game copies and profile storage receive additional safeguards.
- Emulator and Multiplayer windows display the same release number as the launcher.
- Problem reports better hide network addresses and authorization information.

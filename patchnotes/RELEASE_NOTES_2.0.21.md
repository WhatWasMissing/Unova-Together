# Unova Together 2.0.21 — Safer co-op testing and EV resets

Co-op battles now suppress experience, level-up and move-learning rewards by default while this feature is tested. Turn off **Suppress EXP in co-op battles** in launcher Settings to test normal rewards. Resetting a Pokémon’s EVs now asks you to confirm; **No, keep them** is selected first.

# Unova Together 2.0.33 — Safer, compatible AI agent tools

AI coding agents can inspect project source, documentation and asset metadata, inspect a user-selected ROM or save, preview field models, and control an isolated melonDS session through native emulated button and touch input.

This update supports the current stateless MCP protocol and legacy handshake clients. MCP callers can start only the emulator configured in the project build; they cannot provide an executable path. The release includes the tool source, setup guidance, and verification tests, along with credited follower and Mega artwork, the cleared Mega Evolution sound cue, and independent FreeBIOS replacements with their notices.

No game ROM, user save, real firmware dump or generated gameplay capture is included. See [AI agent tools](../docs/AGENT_TOOLS.md), [emulator agent control](../docs/EMULATOR_AGENT_CONTROL.md), [verification report](../docs/AGENT_TOOLS_VERIFICATION_2.0.33.md), and [asset permissions and notices](../docs/RELEASE_ASSET_NOTICES_2.0.33.md).

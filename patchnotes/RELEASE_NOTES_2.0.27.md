# Unova Together 2.0.27 — Area-based battle scenery (test release)

Battle scenery can now reflect the area where an encounter begins, while keeping the center open for the Pokémon. Enable **Area battle scenery** in launcher settings to try it. If the game cannot confirm the area, it keeps the original battle background.

This is a test release. Please try wild and trainer battles in indoor and outdoor areas, especially just after changing maps, and report any scenery that hides the action or shows the wrong area.

Use the same release and supported Blaze Black 2 Redux Complete v1.4.1 game version as your friends. Existing saves remain compatible.

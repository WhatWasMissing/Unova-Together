# Unova Together 1.0.21 — Mega Serperior test

- Mega Serperior now uses the supplied art in the game's DS sprite format.
- Its Mega form uses Sap Sipper instead of Contrary, so you can verify the ability change.
- The exact armed battle state now passes without a crash; your saved Pokémon stays unchanged.
- Use Black 2 Redux Complete v1.4.1, give Serperior Serperiorite, choose **Fight**, then press **L + R together** while choosing a move.
- Mega Serperior is the only Mega in this build. The feature is still experimental; save first. A live two-player Mega battle has not been tested.

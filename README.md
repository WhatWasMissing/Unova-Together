# Unova Together

**Current release: 2.0.15.** Play Blaze Black 2 Redux with friends, explore with your Pokémon, and discover **49 Mega forms**.

[Download Unova Together 2.0.15](https://github.com/WhatWasMissing/Unova-Together/releases/latest)

Unova Together is a free fan project by **mvq1303 / WhatWasMissing**, built on melonDS. It requires an English **Blaze Black 2 Redux Complete v1.4.1** game file. The launcher prepares the Cynthia Route 7 event in a separate copy for this version. No full game patch is currently bundled; if a compatible Unova Together patch is released for another Redux version, use the patch listed for that exact version. Downloads do not include game files, saves, or firmware.

## Mega Evolution

Give a Pokémon its matching Mega Stone, then hold **L + R** while choosing a move in battle. Mega Evolution lasts until the battle ends. Every Poké Mart stocks all 49 Mega Stones for **₽50,000** each, and both Battle Point counters sell the full selection for **50 BP**.

There are 49 Mega forms, including Mega Serperior with Adaptability, Mega Charizard Y with Drought, and Mega Salamence with Intimidate. Gym Leaders in the final three gyms and Cynthia’s Route 7 rematch can also Mega Evolve their Pokémon. Forty-six forms have animated battle artwork. See the [Mega Evolution guide](docs/MEGA_EVOLUTION.md) for every stone, ability and stat total.

After defeating Skyla, meet Cynthia near the Route 7 entrance for a Mega Evolution lesson and a free matching stone. Return farther north for her rematch with Mega Garchomp. See the [Cynthia Route 7 guide](docs/CYNTHIA_ROUTE_7.md) for supported game versions.

## Get started

1. Download **Unova-Together.exe** for the launcher or the Windows x64 ZIP for a portable copy.
2. Open the launcher and choose your own compatible Blaze Black 2 Redux game file. Use a copy patched with Unova Together only when a patch for your exact Redux version is listed.
3. Select **Play**. Open **Co-op** to host or join a game with friends.

Everyone in a co-op session should use the same release and Redux version. The launcher can install updates while keeping saves in place. See the [player guide](docs/PLAYER_GUIDE.md) for setup help.

## More to explore

- Explore together, trade eligible items and Pokémon, and join supported trainer battles.
- Choose an animated field character from your game in launcher settings.
- Bring a Pokémon along; all 649 base species have follower artwork.
- Check IVs and EVs, reset a Pokémon’s EVs for ₽50,000, search ordinary wild encounters, relearn eligible moves, and use supported field HMs.
- Keep the normal bag capacity; all Mega Stones use existing item entries. See the [bag capacity guide](docs/BAG_CAPACITY.md).
- Adjust the camera, save slots, controls, music and optional battle scenery.
- Use the updated in-game mod menus, styled after Generation 5, with optional menu sounds.

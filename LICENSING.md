# Licensing and source

Unova Together is a free fan project. Its modified melonDS emulator is distributed under **GPL-3.0-or-later**. The matching source code and third-party notices are available alongside the Windows downloads on the [release page](https://github.com/WhatWasMissing/Unova-Together/releases/latest). You do not need the source archive to play.

The official Tailscale installer has separate terms. The Windows package does not include Pokémon ROMs, save files, or firmware; provide your own compatible game files.

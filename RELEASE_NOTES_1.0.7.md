# Unova Together 1.0.7 preview

This prerelease adds a searchable Black 2 / Redux practice trainer browser and a launcher-gated flight shortcut. Both build on the loaded game rather than bundling ROM content.

## New

- Search the ROM-backed practice trainer list by trainer name or class. The browser shows party size and level range before starting a no-reward practice battle. Story co-op remains limited to its existing supported trainer set.
- **Settings → Experimental features → Soaring flight** enables **Unova → Pokémon → Take flight**. It opens the native party menu; the game still controls Fly eligibility, destinations and landing.
- Development documentation now describes the next stage for an ORAS-inspired free-flight scene. Free-roaming Soaring is not in this preview.

## Notes

This is a prerelease for development and feedback. The native Windows build and launcher were compiled and packaged from the matching source. This upload does not claim a live ROM playthrough or two-computer co-op playtest of the new trainer browser or flight shortcut. Use copied saves while evaluating development features.

Each player supplies their own supported ROM and save. No ROM, firmware, save, or RAM capture is included. Unova Together's original contributions are by **mvq1303 / WhatWasMissing**; melonDS and dependency licenses and notices are retained.

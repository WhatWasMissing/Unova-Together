# Unova Together launcher

Use the official launcher to choose your game, manage saves, connect with friends, and download updates. Get the latest Windows version from the [release page](https://github.com/WhatWasMissing/Unova-Together/releases/latest).

For setup instructions, see the [Player guide](../docs/PLAYER_GUIDE.md) and [launcher guide](../docs/LAUNCHER.md). The launcher does not include game ROMs, saves, firmware, or room credentials.

Unova Together requires an English **Blaze Black 2 Redux Complete v1.4.1** game file. The launcher prepares the Cynthia Route 7 event in a separate copy for this version. No full game patch is currently bundled; if a compatible Unova Together patch is released for another Redux version, use the patch listed for that exact version. The launcher does not include game files, saves, or firmware.

Choose an animated field character from your game in launcher settings. Added in-game menus have a Generation 5-inspired design and optional menu sounds.
